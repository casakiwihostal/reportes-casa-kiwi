# Reportes Casa Kiwi Hostal

Panel de reportes financieros de Casa Kiwi Hostal (Medellín): reportes semanales, cierres mensuales, proyecciones y marketing.

Se publica con GitHub Pages desde la rama `main`. La página es un solo archivo (`index.html`) con los datos adentro; se regenera cada lunes desde el repositorio privado de datos.
